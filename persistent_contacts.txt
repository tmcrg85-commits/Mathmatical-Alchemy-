PERSISTENT CONTACTS, COMPLEMENTARY COMPUTATIONS

Memory, mixing and developmental topology in a toy cellular reservoir

Xenonostra Research Notes


HOW TO READ THE TAGS

[K] Known. Established in the cited literature, or true by construction.
[T] Toy result. Measured in the simulations reported here. Seeds are fixed and the code is available.
[A] Assumed. A modelling choice or premise that was not tested.
[S] Speculative. A conjecture.
[G] Gap. Something this work does not cover.


ABSTRACT

This note starts from a simple idea. Put very simple cell-like agents in a virtual world, let forces push them to stick together into multicellular bodies, and use those bodies as a computer that improves as it grows.

The idea was tested in a toy world over five rounds of experiments. It did not survive in its original form, and a critical review of the first draft showed that two of our own explanations were wrong as well. Five results remain.

First, contact turnover takes memory out of a fixed readout's reach without removing it from the world. In a freely moving world a fixed readout recovered 0.1 of a possible 100. A decoder trained for a single moment of a replayed movement history recovered 10.9, against 12.4 for the same kind of world frozen. The same decoder used one step later recovered 1.7 [T].

Second, clumping added nothing beyond contact persistence in the comparisons we ran, and in the aggregation experiments no aggregate beat an ordinary random reservoir of the same size [T].

Third, with the local rules used here, worlds that mix and worlds that hold still were good at different tasks. Majority-finding succeeded only where cells mixed, and it also failed on stationary networks that were fully connected [T].

Fourth, in bodies grown by cell division, the depth of the body is an upper bound on memory. How much of the bound is reached depends on where the input enters, how wide the body is and how noisy the cells are [T]. A filament, which is a delay line, held two to two and a half times the memory of the best-tuned ordinary reservoir and matched an engineered ring [T]. Growth is a way of building such wiring. A network assembled with the same wiring computes the same thing [K].

Fifth, a world that is half frozen and half free ran a memory task and a majority task together when each cell sorted its contacts by age. A router that was simply told each cell's type did exactly as well, and so did splitting the cells into two separate worlds [T]. Contact age is a local stand-in for a label. It did not add performance.


1. THE IDEA WE STARTED WITH

The starting picture was embodied computation. Simple single-cell-like agents live in a simulated world. Simulated forces make them chain together into multicellular agents or constructs. The emergent structure does computation that we want, and the whole thing is scaled up.

Three claims are packed into that picture. The first is that aggregation produces computation. The second is that the computation is superior to what we already have. The third is that it scales. Each one can be tested, and each one was.


2. WHAT ALREADY EXISTS

The base version of the idea is not new, and a paper that claimed otherwise would be wrong.

Digital multicellularity. The DISHTINY platform gives simple cell-like organisms the ability and the incentive to unite into higher-level individuals [K, ref 1]. In an evolutionary model by Colizzi and colleagues, cells that search along a weak, noisy chemical gradient evolve into aggregates because the group follows the gradient better than single cells do [K, ref 2]. In Avida, digital organisms evolved division of labour on logic tasks, solving harder tasks from simpler results passed along by neighbours [K, ref 3].

Grown networks. Neural Developmental Programs grow a neural network through a developmental process guided by a second network that uses only local communication [K, ref 4]. Neural cellular automata trained by gradient descent have been reported as promising and efficient on abstract grid tasks, in a paper that also notes the leading results came from language-model methods [K, ref 5].

Structure without a fitness function. Random, non-replicating programs placed in an environment with no explicit fitness landscape tend to give rise to self-replicators [K, ref 6]. Against that, artificial life systems such as Tierra and Avida produce rich diversity early and then stop producing novelty [K, ref 7], and it has been argued that the shortfall is not only a lack of computing power [K, ref 8].

Reservoir computing. A reservoir computer is a fixed dynamical system with a trained linear readout. Its memory capacity is the summed accuracy with which past inputs can be reconstructed from the present state [K, ref 9]. Cellular automata have been used as reservoirs [K, ref 10]. A simple deterministic ring performs comparably to standard random reservoirs, and for linear rings the memory capacity can be brought arbitrarily close to the proved optimum [K, ref 11]. That optimality result is for linear rings and does not carry over automatically to noisy nonlinear ones.

Two results on structure and memory need care. Networks of threshold-like units have an optimal amount of modularity for memory, but the same study found no such effect for linear or tanh units, where modular structure restricted information flow [K, ref 12]. And in a Fisher-information measure of memory, which rates signal-to-noise and is not the reconstruction score used here, no network of N units exceeds N, chain-like networks reach a value proportional to N, and saturating units limit it to about the square root of N [K, ref 13].

Moving agents as reservoirs. A swarm of simulated agents has been used as a reservoir, with the finding that the naive implementation is very inefficient because the agents are interchangeable [K, ref 14]. Driven active matter has an optimal computing regime just below critical damping, and the authors describe the area as being in its infancy [K, ref 15].

Liquid and solid brains. Systems whose parts move and have no persistent connections, such as ant colonies and immune systems, have been called liquid brains, in contrast to solid brains with fixed architecture. What each kind can and cannot compute is posed as an open question [K, refs 16, 17]. Mobile agents solve consensus problems more effectively than similar stationary systems [K, ref 18]. Animal groups with persistent modular structure sit between the two [K, ref 19].

Plasticity. A recurrent network with three local plasticity rules performs much better on prediction tasks than fixed random networks, and all three rules are needed [K, ref 20].

Agents that bond. In the theory of population protocols, identical finite-state agents that meet at random compute exactly the semilinear predicates, a small class [K, ref 21]. In the network constructor model the same kind of agents can also switch pairwise connections on and off, and protocols exist that build a spanning line and use it to simulate a Turing machine [K, ref 22]. A stronger result needs further assumptions: an interaction network that starts out connected, nodes that can detect when their degree equals a small constant, and either a unique leader or the ability to detect a common neighbour. Under those assumptions the model computes, with termination, any symmetric predicate that a Turing machine decides in space proportional to the square of the population [K, ref 23]. Bond switching alone is not the stated sufficient condition.

Two ways to become multicellular. Biology distinguishes coming together, where independent individuals aggregate, from staying together, where offspring do not separate after reproduction [K, ref 24].

The original idea was a coming-together idea. Sections 4 to 7 test it. Section 8 looks at staying together.


3. THE TOY WORLD

World. N cells sit on a square grid with wrap-around edges at a density of 0.25. All cells are updated in parallel. On each step a cell attempts a hop with probability q times (1 - p) raised to the number of its occupied neighbours, where q is 0.5 unless stated. It picks one of the four directions at random and moves only if that site was empty at the start of the step. If several cells pick the same empty site, one is chosen at random and the others stay.

The number p is adhesion. At p = 0 the cells are a free gas. At p = 1 a cell that touches another never moves again. For sequential updates this is a lattice gas with nearest-neighbour attraction, which condenses near p = 0.83 by Onsager's exact solution and the standard lattice-gas mapping [K, ref 25]. Updates here are parallel, so that value is a reference line and not a prediction for this code [A].

Signals. Each cell carries one number. All cells hear the same input u(t), drawn uniformly between -1 and 1. A cell's next state is

x_i(t) = tanh( sum over touching cells j of W_ij x_j(t-1) + v_i u(t) ) + noise.

The pairwise weights W_ij are a fixed random table with standard deviation 0.5, the input weights v_i are uniform between -0.3 and 0.3, and the noise has standard deviation 0.001 [A]. Cells talk only when adjacent. Nothing in the world rewards computation: movement ignores the signals.

Readout. A linear ridge readout over all cell states, with a separate weight for each cell, is trained on 4,000 steps for worlds of up to 1,000 cells and on four steps per cell above that, then tested on the next 1,500 steps. Ridge strength is picked from six values on the last fifth of the training steps and the readout is then refitted on all of them.

Memory score. For each delay k from 1 to 100, the score is the predictive R squared on the test steps, meaning 1 minus the squared error divided by the variance of the target. It is not a squared correlation. Negative values are set to zero. Memory capacity is the sum over delays. When the targets are taken from an unrelated input sequence, this score comes out between 0.00 and 0.03, so the clipping adds almost nothing (Table 4E).

Nonlinear score. NARMA-10 error, with the target y(t+1) = tanh( 0.3 y(t) + 0.05 y(t) [y(t) + ... + y(t-9)] + 1.5 s(t-9) s(t) + 0.1 ) and s(t) = 0.25 (u(t) + 1). The tanh is added so the target cannot diverge. Lower is better.

Contact survival. The fraction of touching pairs at a reference time that are touching again a given number of steps later. A pair that separated and came back counts as surviving. Contact age, used in section 8, is stricter: the number of consecutive steps the same partner has been adjacent.

Conditions. Live: the world keeps moving during the task. Frozen: the geometry is frozen after a burn-in of 10,000 steps. Scrambled: the frozen contact graph with degree-preserving edge swaps, which keeps each cell's number of links and changes everything else about the wiring. Ordinary random reservoir: a sparse random network of the same size with ten inputs per unit, scaled to spectral radius 0.9 and not tuned further.

All results are means over 3 to 10 seeds, with the count stated where it matters. Seed counts are small, so differences are reported with standard errors where the design pairs runs by seed, and a difference that was not detected is not a demonstration that two things are equal. The numbers behind every result are in four data tables, placed after sections 4, 7 and 8.


4. CONTACT TURNOVER TAKES MEMORY OUT OF A FIXED READOUT'S REACH

With 400 cells, live memory capacity was 0.1 to 0.2 out of 100 for every adhesion up to 0.7. It rose to 0.9 at p = 0.8, 2.9 at 0.85, 5.5 at 0.9, 8.9 at 0.95, 10.6 at 0.98, and 15.5 at p = 1, where the world has stopped moving [T, 5 seeds].

That looks like a jump at the aggregation transition. Aggregation is not what causes it. Freezing the dispersed, non-sticky world gave 13.5, so the cells did not lack capacity [T]. With no adhesion at all and cells that simply hopped less often, live memory came back along a similar curve [T].

At the base setting we measured the fraction of contacts that survive the readout's whole lifetime of 5,700 steps. Sticky worlds kept 15, 41 and 61 percent of their frozen capacity at contact survival of 0.16, 0.58 and 0.80. Slow non-sticky worlds kept 9, 19 and 38 percent at survival of 0.05, 0.14 and 0.37 [T, 4 seeds]. The comparison was repeated at a stronger coupling and at a higher density, with survival measured over 1,000 steps. Where the two routes overlapped in contact survival, no additional advantage for the sticky route was detected in any of the three settings [T]. These runs are not paired and no equivalence test was done.

The share kept is not one universal curve. Near a contact survival of 0.57, a random network with no space kept 28 percent and the clumped world 41 percent, while the dispersed slow world kept 38 percent at a survival of only 0.37 [T]. That ordering suggests that turnover costs more in more connected worlds [S].

The readout is fragile to very slow change. In a random network with no space at all, redrawing each link with probability one in ten thousand per step cut capacity from 22.5 to 6.2 [T, 4 seeds]. Re-fitting the readout every 100 steps on the previous 1,200 recovered only part of the loss, 12.1 against a frozen value of 22.4 at p = 0.95 [T]. That re-fitting window itself spans changing geometry, so it does not tell us where the memory went.

Is the memory gone, or only unreadable?

The first draft of this note said that movement destroys the memory. That went beyond the measurement. A low score can mean that past inputs leave no recoverable trace. It can also mean the trace is there, but its relation to the individual cell states changes faster than a trained readout can follow.

To separate the two, one movement history was replayed with 3,000 independent input sequences. A decoder was trained across those repetitions for one single moment and tested on repetitions it had not seen. It asks whether the information exists at that moment, given complete knowledge of how the world moved [T, 4 seeds, delays of 1 to 40 steps].

The freely moving world scored 10.9. The same kind of world frozen scored 12.4. Clumps at p = 0.9 and 0.95 that were still moving scored 19.4 and 21.5, and frozen clumps at p = 0.95 scored 21.5.

So a moving world holds about as much of its input history as a still one. What it loses is a stable code. The decoder trained for one moment and applied one step later recovered 1.7 in the freely moving world, and 0.6 five steps later. In moving clumps at p = 0.95 it recovered 19.4 after one step, 16.5 after five and 8.9 after fifty. In frozen worlds it did not decay.

This decoder is a diagnostic and not a usable readout, because it needs the same movement history replayed thousands of times. The practical statement is narrower than the one we first made: contact turnover puts memory out of reach of any readout that has to keep working for longer than the contacts last.

Clumping does add something when stillness is equal. Frozen clumps at p = 0.95 scored about 22 against 13.5 for frozen dispersed cells, with about three links per cell instead of one [T].

5. IN THE AGGREGATION EXPERIMENTS, NOTHING BEAT AN ORDINARY RESERVOIR

Across eight parameter settings with eight seeds each, paired by seed, an ordinary random reservoir scored higher on average than frozen clumps in every setting. In five settings the paired difference was 3.3 to 11.4 points and more than twice its standard error. In the other three it was 0.3 to 2.8 points and less than one and a half standard errors, which is a failure to detect a difference and not evidence that the two are equal. Clumps were never ahead [T, Table 2C].

Scaling was sublinear for everything. From 100 to 1,600 cells, frozen clumps went from 14 to 27 and the ordinary reservoir from 18.5 to 33. Sixteen times the cells bought about twice the memory. The live dispersed world stayed near zero at every size [T, 5 seeds]. Larger worlds are also harder to fit with the same amount of data. At 800 cells, four times as many training steps raised scores by 3 to 11 percent (Table 4E), so limited training explains a small part of the flattening at that size. It was not checked at 1,600 cells [G].

Clumps scored higher than the same contact graph after degree-preserving scrambling in seven of eight settings, by 1.5 to 6.8 points, and not at the weakest coupling [T, Table 2C]. We do not know why. The first draft put this down to modularity and cited ref 12. That was a misreading. The cited benefit is for threshold-like units, and for tanh units like ours that study found no such benefit. Scrambling also changes loops, path lengths and the number of separate pieces all at once, so this control cannot isolate any one of them [G].


6. LETTING STICKINESS DEPEND ON THE SIGNAL DID NOT HELP

If random change is harmful, perhaps change driven by the signal is useful. Each cell tracked the running strength of the signal it received from its neighbours and set its stickiness from it. Three rule families were fixed in advance: keep contacts that carry signal, keep contacts that are quiet, and keep contacts when the received signal is near a target. The target rule was run with two targets, which makes four variants. Each variant was run at two coupling strengths, giving eight combinations. Each was compared with a control in which every cell read some other cell's signal, and with the whole family of blind adhesion values.

Of the eight combinations, seven sat on or below the curve traced by blind worlds with similar contact survival, and one sat about two points above it. None came near the fully stuck blind world. At the weaker coupling the best rule scored 9.4 live, the blind world at p = 0.98 scored 9.8, and the blind world at p = 1 scored 14.5. At the stronger coupling the best rule scored 9.4 and the fully stuck blind world scored 14.8 [T, 5 seeds]. The best live world was always the one that had stopped moving.

This does not show that signal-driven structure is useless. In fixed networks, three plasticity rules had to act together before the network outperformed random ones [K, ref 20]. Our rules were single and simple. One hint was not followed up. The target rule with the higher target was the combination that sat above the blind curve, and when its structure was frozen after growing it scored 23.8 and 19.0 at the two couplings, against about 20 and 15.5 for blind structures, a lead of one to two standard deviations [T] [G].


7. WORLDS THAT MIX AND WORLDS THAT HOLD STILL COMPUTE DIFFERENT THINGS

The memory task favours fixed wiring. A second task was chosen to favour mixing. Each cell holds an opinion, 55 percent start with the majority opinion, and each cell adds the opinions of the cells it touches into a counter clipped at plus and minus 5 and takes the counter's sign. The score is the fraction of cells holding the true majority after 3,000 steps. The opinion and the memory signal are separate state variables that do not affect each other.

In the liquid world every one of ten runs reached the true majority. At p = 0.4, nine of ten did. At p = 0.7, one of ten. At p = 0.8 and above, none, and the final fraction stayed between 0.58 and 0.70. Slow non-sticky worlds also failed within the time allowed [T, 10 seeds].

A stationary world could fail for a duller reason. Frozen clumps are separate pieces, and the largest clump at p = 0.95 holds only 15 percent of the cells, so no rule could spread an opinion across them. To check, the same rule was run on two stationary networks in which every cell is connected to every other by some path: a fully occupied lattice, and a random network with four links per cell. None of ten runs on either reached the true majority, and the final fraction stayed between 0.60 and 0.70 [T, Table 4B]. With this rule, cells that keep the same neighbours lock into local agreement. Mixing is what lets a cell sample the population. This is a statement about this rule. Other protocols may solve majority on stationary connected networks [G].

So the same knob moves the world from one kind of computation to the other, and no adhesion setting did both. Memory that a fixed readout can use switched on over the same range in which majority-finding switched off.

A fair objection is that the memory readout has a separate weight for every cell, which a liquid cannot support. Two alternatives were tried, with the square of past inputs as the target. A readout given each cell's state and squared state, still with a separate weight per cell, recovered a one-step echo worth 0.67 in the liquid, against 5.6 for frozen clumps. A readout given only two population averages, the only one of the three that is blind to cell identity, recovered 0.05 [T, 5 seeds]. Section 4 gives the more direct answer: the information is present in the moving world, and none of these fixed readouts can follow it. Readouts built on spatial density fields, as used in swarm reservoirs [K, ref 14], were not tried [G].

8. WHAT SURVIVES: THREE RULES, EACH NARROWER THAN FIRST CLAIMED

Rule 1. Use local growth to build persistent, directed signal paths.

Bodies were grown from one cell. A daughter stays attached to its parent, and signals pass one way, from parent to child, with a gain of 0.99 and a random sign. Every cell also hears the input, with weights between -0.1 and 0.1. Three growth rules were compared. In a filament, only the newest cell divides. In a disc, cells with a free side divide. In a bush, any cell divides. Baselines were a blob, which is the same disc-shaped body with all touching cells coupled both ways, an engineered ring, and an ordinary random reservoir at two spectral radii. The blob and the random reservoirs were scaled globally to the stated spectral radius. Delays up to 800 steps were scored.

Depth is a bound. Depth here means the number of parent-to-child links on the longest chain. In a noiseless linear version of such a body, the state is x(t) = A x(t-1) + b u(t), and because signals only travel away from the root, A applied D + 1 times gives zero for a body of depth D. The state is then a sum of A^k b u(t-k) for k from 0 to D, so no input older than D steps leaves any trace [K, by construction]. Whether the inputs inside that window can be told apart depends on noise, saturation, where the input enters, and how well separated the vectors b, Ab, A^2 b and so on are.

In the grown bodies the bound was nearly reached. Discs had mean depths of about 12, 16, 21, 29 and 41 links at sizes of 100, 200, 400, 800 and 1,600, and capacities of 10.8, 15.0, 20.2, 27.2 and 37.5. Bushes had mean depths of about 9 to 15 and capacities of 8.3 to 14.4. Capacity was 92 to 97 percent of depth [T, 4 seeds]. A disc's depth grows roughly as the square root of its size and a bush's as the logarithm, so in these runs the growth rule set how capacity scaled.

Depth alone does not fix memory. With depth held at 20 links, capacity ranged from 0.0 to 19.9. Input delivered only to the last layer gave nothing. Input to the first layer, or to every cell, gave 17.5 to 19.9 at low noise. With cell noise raised to 0.05 a body one cell wide scored 3.8 and a body twenty cells wide scored 9.6, with input to every cell [T, Table 4D]. The first draft said memory equals depth. The supported statement is that depth caps it.

The filament scored 63, 88, 109, 125 and 141 at the five sizes. The best-tuned ordinary reservoir scored 25, 35, 44, 54 and 69. The filament was ahead by a factor of 2.0 to 2.5 at every size [T]. With cell noise raised tenfold and fiftyfold, it stayed ahead by a factor of 2.3 to 3.1 [T, 3 seeds]. The blob stayed flat near 16.

Four qualifications. The filament is a delay line and its advantage is the advantage of a chain. It matched the engineered ring baseline, which scored 74 to 144, and did not beat it. Its capacity fell far short of its depth and did not grow in proportion to size. More training data moved its score by 4 percent at 800 cells, so the flattening is not mainly a fitting problem at that size. On the nonlinear task the filament, the ring and the ordinary reservoir scored about the same at low noise, with errors of 0.36 to 0.40, and bushes and blobs were worse.

What growth does and does not contribute. A network assembled by any other means with the same final connections, weights, input weights and starting state computes exactly what the grown one does [K, by construction]. Growth is a local procedure for building a useful wiring pattern, and that is the whole of the claim. The growth experiments also used a different signalling rule from the contact worlds of sections 4 to 7: one-way links with a fixed gain instead of two-way links with random weights, input weights of 0.1 instead of 0.3, and delays scored to 800 instead of 100. Comparisons inside each experiment are matched. The two experiments cannot be compared with each other, and nothing here shows that a grown body out-computes an assembled one. The one matched comparison of signalling schemes is inside the same disc-shaped bodies: one-way parent-to-child signalling scored 10.8, 15.0, 20.2, 27.2 and 37.5, and two-way signalling between all touching cells scored 15.7, 15.9, 16.2, 16.9 and 16.7. One-way signalling was lower below 400 cells and higher above [T].

Rule 2. Keep the wiring still for as long as the readout has to last.

This is section 4 turned into a rule. A moving world still holds the input history, but a readout trained on it goes stale within a step or two when cells move freely and within tens of steps when clumps rearrange slowly [T, Table 4A]. In every comparison the best live world for a fixed readout was the one whose contacts had become permanent [T].

Rule 3. Contact age can stand in for a cell-type label.

Each cell tracks how long each of its contacts has lasted. Memory signals pass only over contacts at least 200 steps old. Opinions are taken only from contacts younger than 20 steps. Old contacts act as wiring and new contacts act as samples of the population. The two tasks use separate state variables and do not interact. Each cell stores up to four contact ages, a counter and an opinion in addition to its signal value, and that storage is part of the cost.

The first trial used a frozen core with 25 percent free cells. Routing protected the core's memory, 13.9 against 7.2 without routing and 15.4 when fully frozen. Majority-finding was unreliable: three of five runs reached the true majority and two settled on the wrong one [T, 5 seeds]. The free fraction was then raised to 50 percent. Because that choice was made after seeing results, it was run on ten fresh seeds.

In that run, the routed half-frozen, half-free world held a memory capacity of 12.4, which is 86 percent of the 14.5 it scored when fully frozen. It found the true majority in six of ten runs by step 3,000 and nine of ten by step 5,700. Nine of ten is encouraging and not precise: the 95 percent interval for the underlying rate runs from about 60 to 98 percent. The same world without routing scored 5.4 and zero of ten. The all-liquid world scored 0.2 and ten of ten. The all-frozen world scored 15.4 and zero of ten [T, 10 seeds].

Three controls show what contact age is and is not doing [T, Table 4C, same ten seeds]. A router that was told which cells are frozen and which are free scored the same: a memory of 12.4, with a paired difference of 0.01 and a standard error of 0.02, and the true majority in six of ten runs by step 3,000 and ten of ten by step 5,700. So contact age adds nothing beyond the partition that was designed into the world. It recovers that partition from local information, without any cell knowing its partner's type. When the ages were shuffled among each step's contacts, so that the same number of links were admitted but the wrong ones, memory fell to 2.2 and majority-finding to one of ten. It matters which links are used, and not how many. And when the same 400 cells were split into two separate worlds, 200 frozen cells alone held a memory of 12.4 and 200 free cells alone found their majority in nine of ten runs by step 3,000. The shared world gained no performance over that split and was slower on the majority task. What it adds is that the frozen cells are counted in the vote and learn the result.

Routing is not a cure for churn. In worlds made only of sticky cells whose clumps keep rearranging, it changed memory from 9.6 to 10.1 [T]. The core has to be truly frozen.

9. WHAT WE GOT WRONG ALONG THE WAY

We expected the jump in memory near the aggregation point to be caused by aggregation. It was caused by contacts lasting.

We then said that movement destroys memory. It does not. The information stays in the moving world and the readout loses track of it.

We expected spatial clumps to add nothing over scrambled wiring. They added a few points in seven of eight settings. We then explained that with a modularity result that does not apply to our kind of unit.

We said memory equals body depth. Depth is a ceiling, and input placement, width and noise decide how close a body gets.

We expected a filament's memory to grow in proportion to its length. It flattened.

We expected a disc to overtake a filament when cells were noisier, by loose analogy with a square-root limit that belongs to a different measure of memory [K, ref 13]. It did not, at the two noise levels tried.

We expected contact-age routing to rescue churning clumps. It did not. We then presented it as a source of gain. A router given the labels did the same, and so did two separate worlds.

The first two-cell-type setting returned the wrong majority in two of five runs.

We called an engineered ring the known optimum and described a network-constructor theorem without its assumptions. Both statements have been corrected in section 2.


10. WHAT THIS DOES NOT SHOW

It does not show that growing a body is computationally better than assembling one. The same wiring computes the same thing however it was built.

It does not show emergence. The rules were designed. Nothing in these runs evolved or learned a growth rule or a routing rule [G].

It does not show superiority. In the aggregation experiments nothing beat an ordinary reservoir, and the best grown body matched a ring baseline [T].

It does not show linear scaling. Every curve was sublinear over the range of 100 to 1,600 cells [T].

It does not show that the two computations help each other. They ran side by side on separate state variables [T].

The statistics are thin. Seed counts are 3 to 10, most comparisons across conditions are unpaired, and no equivalence tests were run. Words like "matched" and "the same" mean that no difference was detected at this sample size.

It covers one family of worlds, one readout type, small sizes and two tasks [G]. Majority-finding was scored on a fixed time budget and with one local rule [G].

Active-matter reservoirs compute with moving agents by reading positions and velocities [K, refs 14, 15]. Our statements about liquid worlds apply to contact signalling with the readouts tried here, not to liquids in general [G].

Novelty is not established. The hybrid of liquid and solid organisation is in the literature [K, refs 16, 19]. In a limited search we did not find the time-specific decoder comparison for moving contact networks, or contact age used to separate two computations [G].

The link to network constructors is an analogy. Their results concern exact discrete computation by hand-written protocols, under a random scheduler and with the extra assumptions listed in section 2 [K, refs 22, 23]. Ours concern analog memory in a spatial world.


11. PREDICTIONS THAT WOULD FALSIFY THE CLAIMS

P1. In a contact-signalling world, a decoder trained for a single moment recovers most of the memory of the frozen world, and the same decoder loses most of its score within a number of steps set by contact turnover. It fails if the time-specific decoder also scores near zero in a moving world, which would mean the information itself is lost.

P2. With a fixed readout, the share of frozen capacity that survives rises with contact survival. No additional advantage from clumping was detected at matched survival in the tested comparisons. This weaker claim fails if a properly paired test finds that clumped worlds keep a clearly larger share.

P3. In a body with one-way parent-to-child signalling, memory capacity does not exceed depth. It fails if such a body scores above its depth by more than the uncertainty of the estimate.

P4. Where the frozen and mobile parts of a world differ sharply in contact lifetime, a contact-age router performs like a router given the cell-type labels. It fails if the two differ. Ignoring young contacts was sufficient in the one case tested. It was not shown to be necessary.

P5 [S]. A growth rule placed under selection for a memory task will move toward deeper bodies with input reaching the early layers. Untested.

P6 [S]. A readout that is re-estimated faster than contacts turn over can use a moving world. The sliding re-fit in section 4 was too slow to test this cleanly. Untested.


12. CONCLUSION

The idea that cells gathered by force will compute, and compute better as more are gathered, did not survive a toy test. Gathering was not the active ingredient.

What the experiments support is narrower. A world of signalling cells keeps a record of its recent input whether it moves or not. A trained readout can only use that record while the contacts hold still. Worlds that mix can do a population-sampling task that worlds with fixed neighbours could not do under the same rule. Depth caps the memory of a one-way body, and a growth rule is one local way to build depth. Contact age lets a cell tell wiring from passing encounters without being told which is which, and that is all it was shown to do.

None of this is shown to be emergent, superior or scalable in the sense the original idea hoped for.
